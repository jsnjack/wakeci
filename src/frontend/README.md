# frontend

## Project setup

```
npm install
```

### Compiles and hot-reloads for development

```
npm run serve
```

### Compiles and minifies for production

```
npm run build
```

### Run your tests

```
npm run test
```

### Lints and formats files

```
npm run lint:fix
npm run format
```

`npm run lint` and `npm run format:check` only check; `make check` runs both.
